# Secure OTP Authentication Lab

A local application security lab exploring the design, vulnerabilities,
attacks, and hardening of OTP-based authentication.

## Goals

- Implement a basic OTP authentication flow
- Identify security weaknesses
- Reproduce common OTP attacks in a controlled local environment
- Implement defensive mitigations
- Document the reasoning behind each security control

## Environment

This project runs entirely locally.

SMS delivery is simulated using a mock SMS service that prints OTP
messages to the development terminal. No real SMS provider or real
phone numbers are used.
